The whole front end runs on these endpoints. Writes are attributed through the X-Napell-User header; omit it and the event is attributed to the system identity.

Authentication and attribution

This demo build is offline and unauthenticated so it can be reviewed without credentials. Attribution is still enforced: every write records the actor that performed it, and that actor is hashed into the event. 

curl -X POST http://127.0.0.1:8780/api/v1/batches \
  -H "Content-Type: application/json" \
  -H "X-Napell-User: erik" \
  -d '{"module":"JP-01-M02"}'
For production the header is replaced by a signed JWT carrying the operator's GrowerID, so an event can never be attributed to a party that did not send it.

Python

import requests

API = "http://127.0.0.1:8780/api/v1"
H = {"X-Napell-User": "erik"}

# 1. a chamber reports a reading
requests.post(f"{API}/modules/HK-01-M01/telemetry", headers=H,
    json={"ec": 1.68, "ph": 5.79, "air_temp_c": 26.1, "attest": True})

# 2. sow a batch into that chamber
lot = requests.post(f"{API}/batches", headers=H,
    json={"module": "HK-01-M01"}).json()["batch"]

# 3. drive it through the lifecycle to harvest
for stage in ["BATCH_GERMINATED", "BATCH_VEG", "BATCH_FLOWERING",
              "BATCH_FRUITING", "BATCH_HARVESTED"]:
    r = requests.post(f"{API}/batches/{lot['code']}/advance",
                      headers=H, json={"stage": stage}).json()
    if stage == "BATCH_HARVESTED":
        print("dossiers issued:", list(r["auto_issued_reports"]))

# 4. read the consumer-facing journey
j = requests.get(f"{API}/consumer/{lot['qr_token']}").json()
assert j["integrity"]["chain_ok"]

Behaviour worth knowing

Harvest auto-issues compliance. Advancing to BATCH_HARVESTED writes the LCA and the EUDR dossier and anchors both, in the same transaction as the harvest event.
Stage order is enforced. Out-of-order advancement returns 409. A batch cannot be roasted before it is milled, and the ledger would show it if it were.
Telemetry attestation is opt-in. Post with "attest": true to anchor a reading. Raw streams stay out of the ledger; only periodic digests go in, which keeps the chain readable.
Comparison legs are labelled. LCA responses carry the aeroponic leg as measured and the conventional leg as a literature baseline, with baseline_vintage stating where it came from.
